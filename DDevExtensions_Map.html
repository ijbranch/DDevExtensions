Plugin Architecture

DDevExtensions uses a modular plugin system. Each feature can be:

  • Enabled/disabled at compile time via conditional defines
  • Disabled at runtime via environment variable: DDevExtensions.DisabledFeatures

All code analysis tools share the Pascal Parser library for consistent code parsing.

Build Dependencies & Installation

CompileInterceptorW.dll must be built first. This separate DLL intercepts the Delphi compiler process using Windows API hooks to provide real-time compilation progress, timing metrics, and error aggregation. The main DDevExtensions.dll communicates with it via shared memory.

DDevExtensionsReg.exe (Installer) handles registration with the IDE. It auto-detects installed Delphi versions (10.2-13.0), allows selective per-version installation, and manages registry entries under HKCU\Software\Embarcadero\BDS\[version]\Experts. No admin rights required.

Build order: CompileInterceptor → DDevExtensions → Installer
