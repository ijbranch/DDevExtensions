Library Path Sorter Debug State - 2026-01-14

STATUS: AWAITING TEST AFTER PC RESTART

ISSUE (RESOLVED in 3.9.1):
Paths appeared greyed out (invalid) in Delphi's Library Path dialog after saving
with the Sorter, even though the paths existed on disk.

ROOT CAUSE:
Delphi's native path format does NOT use quotes at all. It stores paths as simple
semicolon-separated values. When our code added quotes around paths with spaces,
Delphi treated the quotes as literal characters in the path name, making them
appear invalid (because "C:\Program Files\..." doesn't exist as a path name).

FIX APPLIED (version 3.9.1):
1. Removed all path quoting logic from GetPathsFromListBox (FrmLibraryPathSorter.pas:396-409)
2. Removed all path quoting logic from SortPaths (LibraryPathSorter.pas:495-503)
3. Paths are now saved as simple semicolon-separated values, matching Delphi's format
4. Added FChangesApplied flag to track when changes are applied
5. Added reminder dialog when closing the form after changes have been applied
